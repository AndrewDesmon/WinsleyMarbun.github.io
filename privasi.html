Kebijakan privasi

Berlaku sejak 18 Oktober 2026

Ringkasnya: aplikasi ini tidak meminta akun, tidak memasang iklan, tidak memakai alat analitik atau pelacak, dan tidak mengirim progres belajar Anda ke server mana pun.

Data yang disimpan di perangkat Anda

Aplikasi menyimpan data berikut di penyimpanan browser pada perangkat Anda sendiri:

  • Kemajuan belajar: bagian yang sudah dipahami, hasil latihan, tantangan harian, pangkat, dan hasil simulasi.
  • Catatan yang Anda tulis.
  • Pengaturan, misalnya bahasa tampilan, mode malam, dan pilihan suara bacaan.

Data ini tidak dikirim ke pengembang atau pihak lain. Bila Anda memakai fitur Ekspor, file atau kode ekspor sepenuhnya berada di bawah kendali Anda.

Layanan pihak ketiga

  • Hosting (GitHub Pages). Situs ini dihosting oleh GitHub. Seperti layanan hosting pada umumnya, GitHub dapat mencatat data teknis kunjungan, misalnya alamat IP, sesuai kebijakan privasi GitHub.
  • Font (Google Fonts). Saat aplikasi dibuka online, huruf tampilannya diunduh dari server Google. Dalam proses itu Google dapat menerima alamat IP dan informasi browser Anda, sesuai kebijakan privasi Google.
  • Fitur AI (claude.ai). Tanya AI dan ujian lisan tidak berjalan di dalam aplikasi ini. Bila Anda menekan "Buka di claude.ai", Anda berpindah ke layanan claude.ai milik Anthropic, dan yang berlaku di sana adalah ketentuan serta kebijakan privasi Anthropic.
  • Suara bacaan. Fitur Dengarkan memakai mesin teks-ke-ucapan bawaan perangkat atau browser Anda. Sebagian suara yang disediakan browser bersifat online dan dapat memproses teks bacaan di server penyedia browser tersebut.

Anak-anak

Aplikasi ini tidak mengumpulkan data pribadi dari siapa pun, termasuk anak-anak.

Menghapus data

Buka menu Profil, lalu pilih Hapus semua progres dan catatan. Menghapus aplikasi dari perangkat atau menghapus data situs di pengaturan browser juga menghapus semua data aplikasi.

Perubahan kebijakan

Bila kebijakan ini berubah, versi terbarunya diterbitkan di halaman ini dengan tanggal berlaku yang baru.

Kontak

Pertanyaan tentang privasi dapat disampaikan kepada pengembang aplikasi ini.
